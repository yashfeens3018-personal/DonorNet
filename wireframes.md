# DonorNet Wireframes

🔗 **Figma prototype:** https://www.figma.com/design/1xQh4ZnslJlfxPQaSRUvbk/wireframes?node-id=0-1&t=rfybNPnImBz7yMC7-0

## Flows included

| Flow | Screens |
|------|---------|
| Authentication | Splash, Login, Sign Up (role select), Patient / Donor Sign Up, Forgot Password (OTP, reset), confirmations |
| Patient | Home, Browse Donors / Blood Banks (search and filters), Past Requests, Profile, Addresses, Settings |
| Donor | Home, Browse Blood Banks, Notifications, Profile, Addresses, Settings |
| Blood Bank | Patient Requests (accept / reject), My Stocks, Request for Blood, Request History |
| Admin | Dashboard, Approve Patient Signups, Approve Donor Signups, Add a Blood Bank, Search |
